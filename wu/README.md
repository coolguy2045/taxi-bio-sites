# 伍海山先生 MH — Public bio site / 公開人物簡介

Bilingual single-page profile (Traditional Chinese + English). Facts only from public sources (research dated 2026-10-16).

## Open locally

```bash
cd /workspace/wu-hoi-shan-site
python3 -m http.server 8080
# 繁中: http://127.0.0.1:8080/
# English: http://127.0.0.1:8080/en/
```

Or open the HTML files directly in a browser.

| Path | Description |
